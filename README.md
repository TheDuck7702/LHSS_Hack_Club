# LHSS Hack Club Website

Laurel Heights Secondary School Hack Club Website

This repository contains the source code for the official website of the Laurel Heights Secondary School (LHSS) Hack Club in Waterloo, Ontario.

The website serves as the primary information portal for LHSS students in Grades 9–12 interested in computer science, software development, and engineering projects. It provides access to bi-weekly meeting schedules, event registration links, student project showcases, and details on hardware and software grants provided through Hack Club's "You Ship, We Ship" program.
